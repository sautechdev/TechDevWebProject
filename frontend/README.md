# TechDev Frontend

React, HTML, CSS ve JavaScript ile geliştirilecek frontend uygulaması.

## Komutlar

```bash
npm install
npm run dev
```

Geliştirme sunucusu varsayılan olarak `http://localhost:5173` adresinde çalışır.

## Klasör Düzeni

```text
src/
  assets/       Statik görseller, ikonlar ve fontlar
  components/   Tekrar kullanılabilir arayüz parçaları
  layouts/      Sayfa iskeletleri
  pages/        Route bazlı sayfalar
  routes/       Uygulama route tanımları
  services/     API istekleri ve dış servis yardımcıları
  styles/       Global CSS dosyaları
  utils/        Genel yardımcı fonksiyonlar
```
